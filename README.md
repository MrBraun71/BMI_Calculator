# Calcolatore BMI - Croce Rossa Italiana Comitato di Molfetta

Un'applicazione web per il calcolo dell'Indice di Massa Corporea (BMI) sviluppata per il Comitato di Molfetta della Croce Rossa Italiana.

## Caratteristiche

- Calcolo dell'Indice di Massa Corporea (BMI)
- Input per peso (kg), altezza (cm), età e sesso
- Classificazione automatica della categoria (sottopeso, normopeso, sovrappeso, obesità)
- Design moderno con colori sociali della Croce Rossa Italiana
- Applicazione Progressive Web App (PWA) installabile su Android
- Interfaccia responsive per dispositivi mobili e desktop

## Installazione

### Come app web

1. Aprire il file `index.html` in qualsiasi browser web.

### Come app installabile su Android (PWA)

1. Pubblicare la cartella del progetto su un server web che supporti HTTPS (es. GitHub Pages, Netlify, Vercel).
2. Aprire l'indirizzo web con Chrome su un dispositivo Android.
3. Toccare il menu (tre puntini) in alto a destra.
4. Selezionare "Installa app" o "Aggiungi a schermata Home".

## Tecnologie utilizzate

- HTML5
- CSS3
- JavaScript (Vanilla)
- Progressive Web App (PWA) con Service Worker
- Web App Manifest
